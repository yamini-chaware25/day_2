# Student Management System

A Python-based Student Management System using CSV files.

## Features

* Add, Update, Delete students
* Search and Filter students
* Sort student records
* Record count
* Missing value detection
* Duplicate detection
* Average, minimum and maximum marks
* Department-wise statistics
* Exception handling

## Technologies

* Python
* CSV
* Git & GitHub

## Project Structure

```text
student-management-system/
├── management-system/
├── data-analysis/
└── README.md
```

## Run

```bash
cd management-system
python main.py
```
